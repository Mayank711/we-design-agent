Compact status label — sits on cards and rows to flag state.

```jsx
<Badge tone="success">Verified</Badge>
<Badge tone="danger">Cancelled</Badge>
<Badge tone="premium">Top bid</Badge>
```

Tones: `success`, `danger`, `accept` (gold), `info` (blue), `premium` (violet), `neutral`. Pass `icon` for a leading glyph.
